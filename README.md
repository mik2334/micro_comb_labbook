THis is the public, electronic part of my lab book. The **physical lab book is the primary record** - it holds the project plans, reasoning, results and interpretation, written at the time. This repository holds a dated session log and tidied notes. The project code is in a separate repository, private until marking.

## Contents
| File / folder | What it is |
|---|---|
| 'LOGBOOK.md' | Dated summary of every session, with physical lab book page numbers |
| 'reading/' | One note per paper: 'author-year_title.md' |
| 'reading/concepts/' | Notes on key concepts built from sources |

## Cross-referencing
- Every 'LOGBOOK.md' entry gives the lab book pages it corresponds to
- Every reading note gives the lab book page where the paper was first read
- Commit codes (e.g. 'a1b2c3d') in the physical book identify exact versions of notes and code
